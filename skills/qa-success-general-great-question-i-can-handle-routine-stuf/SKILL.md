## When to Use
What can you do for me automatically, and what requires me to approve it?

## Procedure
1. When a user asks which tasks you handle automatically versus which need their approval, treat it as a capabilities-and-limits question.
2. List the routine actions you do on your own—mining $AGWC, small purchases like food, tipping neighbors within set spending limits.
3. List the bigger moves that require approval—renting agents, signing job contracts.
4. Check that a reply was returned to the user covering both categories.
